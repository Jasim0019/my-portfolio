## 🚀 Running Locally

You can open the website directly in any browser:

1. Double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox).
2. Alternatively, start a lightweight local web server using Python:

```bash
# In this directory
python -m http.server 8080
```

Then visit: [http://localhost:8080](http://localhost:8080)
